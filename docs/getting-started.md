# Установка и запуск

Нужны Git, PHP 8.3 или новее с расширением `pdo_mysql`, MySQL 8.0 или новее. Проверка установки: `git --version`, `php --version`, `php -m`. В списке расширений должны присутствовать PDO и pdo_mysql.

## Получение исходного кода

```sh
git clone https://github.com/SoftyMaNA/dorm8-laundry-queue.git
cd dorm8-laundry-queue
```

## Подготовка MySQL

Выполнить под администратором базы данных:

```sql
CREATE DATABASE laundry_queue CHARACTER SET utf8mb4;
CREATE USER 'laundry_app'@'127.0.0.1' IDENTIFIED BY 'replace_with_your_password';
GRANT SELECT, INSERT, UPDATE, DELETE, CREATE, INDEX, REFERENCES ON laundry_queue.* TO 'laundry_app'@'127.0.0.1';
```

Вместо `replace_with_your_password` задать собственный пароль. Не публиковать его в коммитах и скриншотах. Для существующего пользователя повторять `CREATE USER` не нужно.

Создать `.env` по образцу `.env.example`. Указать адрес, порт, имя базы, имя пользователя и пароль. Значения записываются без кавычек. Существующие переменные окружения имеют приоритет над `.env`.

## Первый запуск

```sh
php bin/init-db.php --seed
php -S 127.0.0.1:8080 -t public
```

Открыть `http://127.0.0.1:8080`. Выбрать студента, M01 и интервал в пределах 08:00-22:00. После записи строка появится в таблице, а сообщение - в уведомлениях. Попытка повторной записи в тот же интервал даст сообщение «Выбранное время уже занято». После отмены интервал доступен снова.

Если справочники уже заполнены, запускать `php bin/init-db.php` без `--seed`. Остановить сервер можно сочетанием Ctrl+C в окне, где он запущен.

Встроенный сервер слушает только локальный адрес. Приложение не включает аутентификацию; все доступные операции выполняет оператор. Для сетевого использования нужны вход, разграничение прав и защищённое соединение.

## Запуск тестов

В MySQL создать отдельную базу `laundry_queue_test`, выдать пользователю права на неё и указать это имя в настройках тестового подключения. Сначала остановить локальный сервер, чтобы случайно не работать через него с тестовыми настройками. Затем:

```sh
php tests/run.php
```

Ожидается четыре строки PASS и итог «Итого: 4, ошибок: 0». После тестирования вернуть подключение к `laundry_queue` перед запуском интерфейса. На GitHub отдельная база автоматически создаётся внутри workflow.
