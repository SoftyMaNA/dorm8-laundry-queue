# Состав и границы Windows-пакета

Сборщик: Inno Setup. Целевые системы: Windows 10/11 x64; права администратора
нужны для установки системного компонента Visual C++ и файлов в Program Files.
После установки приложение запускается обычным пользователем.

Компоненты: PHP 8.4.27-1 NTS x64, MySQL Community 8.4.13 x64, Microsoft Visual C++
Redistributable x64. Сборка загружает официальные дистрибутивы; подпись Microsoft
проверяется, версии и SHA-256 всех входных компонентов записываются в components.json.
Установленный пакет не загружает компоненты из интернета.

Сторонние компоненты поставляются с их лицензиями из официальных архивов.
Исходные тексты PHP доступны на https://www.php.net/downloads.php,
MySQL Community на https://dev.mysql.com/downloads/mysql/ (Source Code).
Пакет не изменяет бинарные файлы PHP и MySQL. Приложение и сценарии сборки открыты
в этом репозитории и архиве исходников выпуска. Лицензионные условия сторонних
компонентов продолжают действовать.

Файлы программы находятся в Program Files/Dorm8LaundryQueue. Рабочие данные
находятся в LOCALAPPDATA/Dorm8LaundryQueue. Пароли генерируются отдельно для
каждого профиля. MySQL и HTTP привязаны только к 127.0.0.1, порты выбираются
автоматически. Повторная установка сохраняет базу. Удаление программы также
сохраняет пользовательскую базу; для её полного удаления требуется отдельное
осознанное удаление каталога данных.

Локальный веб-сервер PHP предназначен для запуска на одном компьютере.
Пакет не является серверным развёртыванием для доступа из сети.
Автотесты работают на отдельной базе laundry_installer_test.
Контрольный прогон GitHub Actions выполняется на Windows Server 2022 x64.
Ручная проверка на Windows 10 и Windows 11 должна быть отражена отдельно,
если она выполнена; наличие установщика само по себе её не подтверждает.

В комплекте: установщик, исходники, SHA256SUMS.txt, components.json и фактические
результаты проверки. Скриншоты мастера установки и приложения снимаются на
Windows runner программно, без генерации изображений.
