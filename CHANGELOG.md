# История изменений

Параметры cookie сессии заданы явно: HttpOnly, SameSite=Lax, строгий режим сессии и Secure при HTTPS. Исправление проходит через hotfix с возвратом в main и develop.

## 1.0.0

Создание и отмена бронирований, запрет пересечений, учёт обслуживания машин, уведомления, схема MySQL, четыре теста, Actions и Wiki. Добавлены инструкции для Git, GitHub Desktop и GitHub.
